# 真实故事 AI 短视频提示词包（15秒版）

## 1. 阶段1：故事逻辑审核提示词

```text
请审核以下完整剧本是否成立。审核故事逻辑，不审核摄影美学。

逐项输出：通过 / 待修正 / 不通过，并给出具体修正建议。

检查项：
1. 起因：故事为何从此刻开始。
2. 人物目标：主要人物想得到什么、害怕失去什么。
3. 行动链：行动是否由目标推动。
4. 外部阻力：环境、他人、资源、时间等障碍。
5. 内心困境：犹豫、恐惧、价值冲突、自我怀疑。
6. 冲突类型：人与环境、人与人、人与自我至少覆盖两类。
7. 对话连贯性：每句是否回应上一句，新增信息是否有铺垫。
8. 转折因果：转折是否被前置事件触发。
9. 关系变化：人物是否建立、误解、分离、改变或重新理解。
10. 高潮：是否由阻力和代价累积推出。
11. 结尾：结果是否兑现并回收开头。
12. 主题：是否从个人经历提炼出清晰但不过度说教的意义。
13. 节奏：是否有空转、突跳或仓促收尾。
14. 篇幅：完整故事是否遗漏关键过程；不得靠空镜注水。

额外自检：
- 每句对白是在回应什么？
- 每次情绪变化由什么刺激触发？
- 新人物、物件、地点出现前是否有铺垫？

输出：审核表、问题清单、修订版建议、门禁结论。
若通过，说明可进入阶段2；若不通过，不自动停止，是否进入下一阶段按照用户要求执行。用户明确要求进入下一阶段时，继续进入阶段2；若未明确要求，则停留在阶段1。
剧本：{完整剧本}
```

## 2. 阶段2：画面合理性诊断提示词

```text
请把剧本中的每个画面段落编号，并按五个维度评分，每项0-2分：
1. 物理可执行性
2. 时序因果
3. 场景与道具连续性
4. 剧情信息承载
5. 可拍性：能否画出唯一一帧

对每个低于9分的段落输出：
- 问题定位
- 触发缺失或空间错误
- 具体修正画面
- 是否影响台词、时长、道具或下一段

重点检查：
- 抽象情绪是否转译为可见动作。
- 人物突然反应是否有刺激源。
- 道具是否提前出现。
- 人物是否瞬移或越过轴线。
- 镜头是否同时要求无法完成的动作。
- 台词是否与画面中人物、视线和动作匹配。

输出平均分、需修正段落、严重问题和确认门。
剧本画面：{完整剧本}
```

## 3. 阶段3：时间轴与生产片段切分提示词

```text
基于通过故事逻辑审核的剧本和修正后的画面，执行三层转换：

第一层：完整故事时间轴
- 保留所有剧情节点、因果、行动、代价、关系变化、高潮和结尾回收。
- 为每个节点填写时间范围、地点、行动、前置触发、直接结果和下一步触发。

第二层：画面段落表
- 每段填写时长、动作开始-过程-结果、台词/声音、前置刺激、下一段触发和叙事任务。

第三层：生产片段表
- 每段固定为15秒。
- 片段数量由完整故事时长决定。
- 不删台词、不跳节点、不添加注水对白。
- 默认使用连续的三段区间；如根据动作需要改用其他区间，单个区间不少于3秒。
- 每段开头承接上一段的动作、视线、声音、信息或情绪。
- 每段结尾留下明确可接续落点。

时长估算：
- 台词时长按自然语速估算，字数除以4只能作为参考。
- 动作必须保留开始、过程和结果。
- 停顿、反应、转身、取物和空间移动单独留时。
- 每个生产片段固定15秒；若容量不够就增加片段。

输出：完整故事时间轴、画面段落表、生产片段分配表、台词统计、场景调度、道具状态、色卡和门禁结论。
剧本：{完整剧本}
诊断修正：{阶段2修正内容}
```

## 4. 阶段4：资产图提示词生成

### 4.1 角色四视图提示词

```text
为以下角色生成一张16:9横向角色四视图设定图提示词。

画面结构：左侧为超大面部特写；右侧依次为全身正面、全身侧面、全身背面。
纯白背景；四个视图必须是同一人物；服装、发型、年龄感、体型和肤质一致；全身图自然站立，双手下垂，不持物，不做动作。

必须写清：
- 国籍、性别、年龄感、身高感
- 五官、骨相、肤质、发型
- 外套、内搭、下装、鞋履、配饰
- 面料、颜色、磨损和时代特征
- 写实摄影质感和高分辨率

禁止：多角色合图、剧情道具、完整场景、动作姿势、卡通化、英文说明、额外文字。
角色资料：{角色资料}
```

## 5. 阶段5：导演级分镜提示词

```text
请根据画面段落表，为每个画面输出导演级分镜，严格保持编号和剧情顺序。

每个分镜必须包含：
- 景别
- 构图策略
- 机位高度和方向
- 运镜方式
- 光源方向、色温、光比和阴影
- 色卡：主色/辅色/点缀色
- 人物位置、动作、表情和关键细节
- 台词嵌入、语速、气息、声调和交流对象
- 空间关系、视线方向和轴线
- 材质细节
- 环境音和动作音
- 古装场景的自然风动态
- 时长

规则：
- 相邻分镜不得发生空间瞬移。
- 正反打保持同侧轴线。
- 台词与动作同步。
- 每个镜头只表达一个清晰的主要动作或信息。
- 禁止叠化、淡入淡出、闪白、翻页和溶解等不可控后期特效。

画面段落：{画面段落表}
场景调度：{场景调度}
角色资产：{角色资产}
```

## 6. 阶段6：Seedance 分段提示词生成器

```text
你现在负责把已确认的生产片段和导演级分镜，转换成可直接复制到视频生成工具的分段提示词。

每段输出两部分：

A. 工作校验区：
- 片段编号和时长
- 使用的画面段落编号
- 使用的台词编号
- 台词逐句字数与时长估算
- 本段出镜角色、物品、场景
- 开头承接方式
- 结尾落点
- 是否有遗漏、重复、超时或空间冲突

B. 交付正文：
必须包含：
[出镜角色-物品-场景]
角色：使用固定的@角色名
场景：使用固定的@场景名
物品：使用固定的@物品名
角色-声线绑定：必须结合角色人设，从声线类型、年龄感、语速、情绪、语调、音色特点等维度进行精准描述，并为每个角色建立固定且唯一的声线设定。该声线设定一经确定，后续所有 Seedance 片段必须保持一致，不得随意改变音色、年龄感、语速或语调。
构图：{根据剧本分镜分析}
色彩：{根据剧本分镜分析}

之后用连续时间区间描述：
[0-3秒]、[3-7秒]、[7-11秒]、[11-15秒]，或根据动作需要使用其他不少于3秒的区间。

每个区间必须写：
- 景别、机位、运镜
- 人物具体动作和表情
- 空间左右前后关系
- 光线、色彩和材质
- 台词及同步动作
- 环境音或动作音

统一规则：
- [16:9横屏]，写实电影风格。摄影机：Arri Alexa 65，Panavision Primo 70系列，50mm定焦，光圈T2.8，稳定器极慢推镜。
- 无字幕、无文字叠加、无水印、无logo、无BGM。
- 不要AI油亮皮肤、塑料感、蜡像感和过度磨皮。
- 台词必须逐字保留，不能增删改写。
- 后续所有 Seedance 片段必须严格沿用已绑定的角色声线；角色音色、声线类型、年龄感、语速、情绪和语调保持统一，除非用户明确要求修改。
- 不写“说完后再做动作”，必须描述台词与动作同时发生。
- 第二段起，在第一个时间区间自然写出动作顺接、视线引导、声音桥梁、图形匹配或情绪承接。

【禁止】
禁止画面字幕、水印、台标、进度条、背景音乐BGM；禁止过曝、手指畸形、面部变形；禁止动画、卡通、3D渲染、插画、二次元、游戏引擎渲染风格；面部清晰稳定不变形、五官端正、人体结构比例正常、无多余手指、动作连贯不僵硬。

当前生产片段：{生产片段}
导演分镜：{导演级分镜}
资产编号：{资产编号}
上一段结尾：{上一段结尾落点}
```

## 7. 阶段7：发布物料提示词

### 7.1 标题

```text
根据完整故事生成3个发布标题。

要求：
- 每个不超过20个汉字或字符。
- 至少包含人物/事件、核心冲突或情感钩子中的两项。
- 避免夸张造假、标题党和无依据的“史上最”“震惊全网”。
- 分别提供：逆境反转型、情感共鸣型、历史意义型。
- 标注推荐标题和推荐理由。

故事：{完整故事}
```

### 7.2 标签

```text
生成固定5个发布标签：
1. 人物标签
2. 事件标签
3. 情感标签
4. 内容类型标签
5. 泛流量或价值标签

标签格式为#标签词，避免重复、过宽或与故事无关。
故事：{完整故事}
```

### 7.3 封面

```text

- 设计一个2-4字主题标题，必须概括核心情感或主题。
- 标题使用金色或白色毛笔书法字体，放在画面中上部居中或人物脊柱附近。
- 说明人物姿态、构图、背景、色调、光影、胶片质感和标题位置。
```
